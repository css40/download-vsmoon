Herramientas para crear y aprender

Un espacio de trabajo con editor, utilidades de programación y herramientas para tus proyectos y clases.

⌨️

Editor con pestañas

Edita varios archivos y usa resaltado de sintaxis en los lenguajes compatibles, como Python, JavaScript, HTML, CSS, C++ y Java.

🗂️

Archivos y carpetas

Abre archivos o carpetas de proyecto, navega con el explorador y trabaja en varias pestañas.

▶️

Ejecuta y depura

Ejecuta el documento activo cuando el lenguaje y el entorno están disponibles. Depura paso a paso programas de Python y PSeInt.

💻

Terminal integrada

Ejecuta comandos desde el espacio de trabajo y amplía la terminal cuando necesites más espacio.

🔎

Problemas y estructura

Revisa diagnósticos, ve a su ubicación cuando hay información de línea y consulta la estructura detectada del código.

🌐

Pixel Server

Abre una vista previa local de páginas web mientras trabajas en ellas.

🗄️

Bases de datos

🌿

Git y GitHub

Herramientas para clase

Windows

Instálalo en 7 pasos

Sin complicaciones. Sigue los pasos con las imágenes.

1 Descomprime el ZIP o abre el EXE

Si descargaste un ZIP, haz clic derecho y selecciona Extraer todo. Si descargaste el instalador EXE, ábrelo directamente. Después, abre la carpeta extraída si aplica.

2 Selecciona la carpeta de destino

Deja la carpeta de destino predeterminada o pulsa Examinar para elegir otra. Cuando estés listo, pulsa Siguiente.

3 Selecciona la carpeta del menú Inicio

Puedes dejar vsMOON como nombre de la carpeta de accesos directos. Pulsa Siguiente para continuar.

4 Crea el acceso directo

Marca Crear un acceso directo en el escritorio si quieres tenerlo a mano. Después, pulsa Siguiente.

5 Listo para instalar

Revisa las opciones elegidas y pulsa Instalar para comenzar.

6 Espera a que termine

El asistente copiará los archivos necesarios. Espera a que finalice; no cierres la ventana durante el proceso.

7 Finaliza y disfruta de vsMOON

Pulsa Finalizar y abre vsMOON desde el acceso directo o el menú Inicio. ¡A disfrutar!
